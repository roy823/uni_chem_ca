# 物理与计算范围 · v0.5

局域 CA 本体 `LocalCellEngine` 与独立 HF 参照是不同层。CA 的固定大小局部约化密度、有限接触邻域和三阶段更新已经通过输运、守恒、局部 Pauli 界及规模验收；整体电子/能量/力场模型尚未接入。

当前局域电子通道使用显式 product-state pair 与凸混合闭合，丢弃跨元胞关联；它不是 HF 等价算法，也不认证通用量子化学已正确。大型测试场未训练且核力为零，仅用于本体容量与传播实验。完整能量守恒、真实化学涌现以及 latent 的物理作用需要后续验证。

以下为保留的独立 HF 参照范围。

已实际验证零温 gapped 算子的原子块密度净化、自洽 HF、真实高斯积分、含 Pulay 项的核力以及原生同步核演化。输入是元素、核坐标、总电荷、固定自旋人口、基组与均匀外场，没有学习能量或反应规则。

电子状态是所选单行列式/平均场层的自旋密度核；核是经典连续坐标，电子在每次核提案前后达到自洽状态。本版不是实时多电子 Schrödinger 演化或完整核量子动力学。

零温投影面向已解占据间隙。简并部分占据、金属、电子相关、非绝热过程和一般复杂自旋需要单独的物理方法与验收，不能用隐含软化温度代替。收敛与占据一致性不等于证明找到了所有 HF 解中的全局最低态，复杂体系还需要稳定性分析。

HF/STO-3G 下的水几何和频率可与同方法参照高度一致，但它们不等于实验或 PBE0 数据。例如本轮得到 O–H 约 0.9894 Å、H–O–H 约 100.03°，谐频率约 2169.9、4139.6、4390.7 cm⁻¹；这些反映所选物理近似与基组的误差。架构正确求解这一方法不能被说成实验级化学精度已经达标。

密度核和代数保持原子块结构，使用测量误差的压缩及实际收敛残差。块图和乘法 halo 仍可能填充；预算不足失败。64–512 站点有隙算子的近线性存储结果不认证金属、致密水或完整 HF 积分的线性成本。

现有精确积分供应器有四中心数量与缓存内存预算，未提供大型液体、多 GPU、周期晶体或快多极供应器。保留的格点场工具是独立数值组件，不代表这些能力已经接入物理量子核心。

目前没有正确反应自由能、反应速率、体相 pKw 或通用自电离统计的证明。只读键指标、Mulliken 布居和短振动轨迹不单独认证反应。
