# 进一步实验：复现、集体现象与化学涌现

## 核心问题

同步元胞更新可以复现声明的数值规律。化学涌现需要另外证明：在没有键表、反应式或产物规则的情况下，同一可信能量产生分子结构和电子重排，而且独立参考、时间步与统计检验都通过。

此前水对轨迹使用 `KernelUnrolledPredictor + integrate_potential`。电子预测器每次从确定性种子重建电子态，核做 BAOAB 更新。这不能单独作为原生 `World → SynchronousEngine → World` 元胞电子态持续演化的证据。

必须先统一实验的力定义。训练预测器计算整个有限电子映射的全导数；原生变分执行器在当前独立电子坐标和云宽度下计算偏导。只有定义匹配、必要自由度达到声明的驻点并通过参考验证，才可以比较调度方式或宣称相同化学。

## 分阶段方案

以下阈值是预先设定的工程验收目标，并非文献普适常数。结果达不到时应记录失败，不能改阈值制造成功。

| 阶段 | 实验与条件 | 观察量 | 对照与验收 |
|---|---|---|---|
| A 数值复现 | 原生同步引擎：自由飞行、重排原子、保存/恢复；固定扩散率格点 Fourier 模式 | 连续坐标、电子数、latent 总和、模式衰减 | 与解析离散解比较；坐标/模式误差 <1e-11；CPU 同配置重放逐位一致 |
| B 稳定分子 | 在同一参考方法下先优化水单体，再施加 ±5%/±10% 的几何扰动；NVE 0.05/0.1/0.2 fs，固定 1 ps 总时长 | O–H 长度、H–O–H 角、振动频率、能量漂移 | 几何相对参考误差 ≤0.02 Å、≤2°，主要频率误差 ≤5%；漂移随步长收敛。恢复几何不等于从游离原子自发合成水 |
| C 电子极化 | 固定核、三个方向的弱场 ±0.001/±0.002/±0.004 原子单位；同时计算零场 | 偶极矩、极化率、价电子密度、场能 | 对称有限差分、能量与偶极响应一致；相对参考的响应误差目标 ≤10%；电子数误差 <1e-8 |
| D 优先化学实验 | 带一个过量质子的 Zundel 小体系，扫描 O–O 2.3–3.1 Å；不同距离下做 20 个种子、每组 1–10 ps | 共享质子分布、持续的载体变化、电子分区电荷、条件势能面 | 先过独立曲线 0.043 eV、力 0.1 eV/Å 门槛；不指定哪一个 H 转移；比较同方法参考分布和多个步长 |
| E 可逆重排 | 初始条件为中性 H/O 离子对构型及 6–16 个溶剂水；总电荷 0；每组 20 个种子、5–20 ps | 复合、质子接力、电子重排、时间分布 | 初态是物理坐标，不是执行器产物指令；先验证相应数据域。几何归属变化还需电荷和持续性证据 |
| F 体相自电离 | 在规模和精度达标后比较 32/64/128 及更大周期水盒；充分平衡后采用独立采样研究 | 自由能、有限尺寸收敛、离子对稳定性与速率 | 增强采样偏置与重加权单独记录；平衡自由能和动力学时钟独立校准。两水短轨迹不能测量体相 pKw |

最优先的化学目标是 **极化与可逆质子共享**。Zundel 的势能面随 O–O 距离变化，有明确的理论研究背景：[质子化水二聚体研究](https://arxiv.org/abs/1312.2897)、[Zundel/Eigen 与温度、核量子效应](https://doi.org/10.1038/s41467-023-42366-4)。经典核中的热跨越不能宣称实现了质子隧穿或量子离域。

液态水自电离涉及稀有溶剂重排与氢键网络，适合后期综合验证：[Geissler 等](https://pubmed.ncbi.nlm.nih.gov/11251111/)。短轨迹没有事件，既不能给出可靠速率，也不能否定架构。

## 怎么检验“来自元胞机制”

1. 相同能量、力定义、初始物理状态和数值容差，只改变同步调度、原子存储顺序和分块方式。变化只允许落在声明的浮点误差内。
2. 以相同势能和相同电子精度的常规积分为对照。两种实现复现同一结果说明内核正确；不能仅凭同步执行就声称新物理。
3. 研究电子耦合贡献时，比较“固定电子态”“环境响应电子态”“显式长程场”等消融。分别按相同数据预算重新训练，并报告它们改变了模型假设；不能把关闭一项后发生差异自动当作因果证明。
4. latent 先保持关闭。只有明确能量、噪声、时间尺度及一致性后再加入，并单独检验是否改变平衡分布和动力学。
5. 观察者只读轨迹。质子归属必须稳定超过 2–5 fs，排除中心附近反复摇摆和最近邻阈值抖动。自由能需要平衡与误差区间，速率还需要时间标定。

## 当前可运行部分

```powershell
$env:PYTHONPATH = 'src'
python -m unichem ca-controls --steps 20
python -m unichem reference-screen
python -m unichem design-reference
```

`ca-controls` 直接运行原生同步 World 引擎，检验自由飞行、Fourier 扩散、恒等重放和原子排列。常数扩散率/零能量是明示的解析控制，**不作为化学涌现**。

`reference-screen` 分别检查每个 H/O 家族的独立能量/力、密度、电子数，并比较同一电子态下全导数力与偏导数力。一个几何点的相对能量误差本来就可以是零，所以不会据此通过曲线验收。至少五个点也只是初步筛查，不能替代充分覆盖。

`design-reference` 生成水局部势能面、三轴外场与对称 Zundel 二维面的几何任务；不生成猜测的能量/力。整个 O–O 距离面统一划分，反射相关构型保持同一划分。新协议必须重新训练，旧 checkpoint 已见过部分距离，不能算新协议的独立测试。

本次产生 162 个去重任务，其中对称 Zundel 面 117 点。实际采集参考时，在具备 PySCF 的环境中使用独立目录，保留设计划分：

```bash
python examples/generate_ho_dft.py --jobs outputs/reference_design/jobs.json --output data/designed_pbe0 --check-field
unichem import-designed-reference --root data/designed_pbe0 --output data/ho_designed_pbe0
```

这批 162 个任务已实际完成 SCF。冻结划分为 82 个训练、35 个验证、45 个测试构型；导入目录为 `data/ho_designed_pbe0`。生成器拒绝将不同几何计划写入已有参考目录，导入器必须见到已收敛的真实标签和密度文件。

## 本次首轮结果

原生同步自由飞行误差约 1.78e-15 bohr，Fourier 模式误差约 4.44e-16，latent 通道总和误差约 9.09e-13。同配置 checkpoint 重放逐位一致；随机积分的重启与原子重排也逐位一致。

初始 checkpoint 在原 41 点数据集上只有两个独立 Zundel 验证构型，力 RMSE 约 3.86 eV/Å；全导数与固定电子坐标偏导力的 RMS 差约 4.37 eV/Å。该结果不适合把原生 CA 化学轨迹与预测器轨迹等同。

结果文件：`outputs/emergence_controls/report.json`、`outputs/emergence_screen/report.json`、`outputs/reference_design/jobs.json`。

## 新一轮实际参考与分子对照

162 个真实 PBE0/aug-cc-pVDZ 构型的 AO 电子数最大误差约 8.53e-14，48³ 网格价电子密度积分最大相对误差约 0.226%。额外 24 次有限差分检查覆盖三轴外场方向、水单体和测试 Zundel 构型，最大力偏差约 5.84e-7 Hartree/bohr，通过原定 2e-5 阈值。每个标签均保存 SCF 约定、外场、偶极、能量、力和价电子密度，没有用模型输出充当参考。

冻结其他原子的 Zundel 扫描在 O–O 2.3–2.4 Å 为中心单势阱，2.5 Å 起出现双势阱；2.6 Å 的扫描内中心势垒约 0.0545 eV。这是电子势能切片，不是自由能。2.7–3.1 Å 的最低点落在 ±0.6 Å 扫描边界，只能报告截断扫描的能量差，尚未定位真实最低点和完整势垒。

水参考优化几何为 O–H 0.961624 Å、H–O–H 104.4972°；谐振频率约 1628.2、3853.1、3966.1 cm⁻¹。[PySCF Hessian 与谐分析](https://pyscf.org/pyscf_api_docs/pyscf.hessian.html)用于参考频率，模型使用有限差分 Hessian 并投影掉整体平移/转动；两种参考算法差异约 0.003 cm⁻¹。

增加一个限定于中性零场水单体的纯几何对照，训练/验证构型与新量子模型的水子集相同。独立训练 700 轮，按验证集选第 665 轮：验证力 RMSE 0.06684 eV/Å、能量 RMSE 0.00148 eV/原子。它不学习电子密度、外场响应或离子电荷，不能替代量子模型；两模型训练步数和计算预算不同。

| 纯几何对照观察量 | 实际结果 | 预设目标 |
|---|---|---|
| 自身优化几何的 O–H 误差 | 0.00231 Å | ≤0.02 Å |
| 自身优化几何的键角误差 | 0.08225° | ≤2° |
| 三个模型谐频率 | 1626.3、3885.6、4003.5 cm⁻¹ | 相对参考误差 ≤5% |
| 三个频率相对误差 | 0.119%、0.842%、0.945% | 全部通过 |
| NVE 总时长 | 0.2/0.1/0.05 fs 步长，各 1 ps | 固定总时长比较 |
| 最大能量平衡误差 | 1.033e-4 / 2.582e-5 / 6.456e-6 eV | 随步长收敛 |
| 步长减半的误差比例 | 约 4 / 4 | 二阶收敛 |

频率来自模型自身驻点处的 Hessian，不是从短轨迹拟合三条振动峰。NVE 从模型优化几何的 O–H 长度增加 2%、零动量开始，验证稳定振动与积分收敛；不声称从游离原子自发生成水。

再把完全相同的几何能量放入原生 `SynchronousEngine`，运行 20 步、2 fs。与独立核回调积分器的最大坐标差约 5.33e-15 bohr，checkpoint 重放逐位一致，原子重排误差为零。该对照的电子态不参与能量。它验证原生核更新与同能量对照的一致性，不验证有限电子预测器与变分电子执行器的等价性。

## 新量子模型的独立结果与下一步排序

新模型完成 10 轮、820 次训练更新，没有恢复旧权重；按原有能量/力/密度组合分数选第 10 轮。验证每原子能量 RMSE 0.3992 eV、力 RMSE 2.1125 eV/Å、密度 L2/电子 0.03507。第 5 轮力误差更低（1.6673 eV/Å），第 10 轮密度误差更低；按预先固定的组合准则选模，没有根据测试结果修改权重。

| 整体留出的 Zundel 距离面 | 以中心点为零的曲线 RMSE | 力 RMSE | 验收 |
|---|---|---|---|
| 2.6 Å | 0.5054 eV | 2.0436 eV/Å | 未通过 |
| 3.0 Å | 0.5746 eV | 2.1413 eV/Å | 未通过 |
| 3.1 Å | 0.7220 eV | 2.4516 eV/Å | 未通过 |

模型在九个距离面都预测中心双势阱，错误地把 2.3–2.4 Å 的参考单势阱也变成双势阱。部分距离的势阱类型相同不能当作质子共享已经验证。三个完整测试面共 39 点的去常数偏移能量 RMSE 为 0.3059 eV；该指标与上表逐面中心锚定值不同。

| 水极化率，场强 ±0.001 au | DFT 能量响应 | 模型能量响应 | 模型密度响应 |
|---|---|---|---|
| x，bohr³ | 9.5759 | 0.19947 | 0.10005 |
| y，bohr³ | 9.3819 | 0.13832 | 0.06932 |
| z，bohr³ | 8.6686 | 0.02238 | 0.01894 |

三轴极化率相对误差约 97.9%–99.7%，±0.004 au 测试场也失败。能量和密度响应之间仍有差异，有限电子映射尚未恢复正确极化。尽管最大电子数误差仅约 8.2e-14，守恒与 Pauli 参数化并不保证响应正确。

两个选定构型的模型力与同一有限映射能量差分符合至约 3.1e-9 eV/Å，说明这些点的全导数实现一致；它不保证整个模型是正确的 DFT 势能。抽样原生偏导/全导数力差最高约 6.84 eV/Å，仍不能将两条量子部署路径视作相同物理。

独立水参考几何的整体平移审计发现显著网格误差。下面的模型权重固定，改变的仅是同一 28.8-bohr 真空盒的网格；半格平移在不同网格上分别为 0.3/0.2/0.15 bohr：

| 网格间距 | 最大平移能量变化 | 原参考几何的 DFT 力 RMSE |
|---|---|---|
| 0.6 bohr | 0.50947 eV | 2.8429 eV/Å |
| 0.4 bohr | 0.001305 eV | 3.7080 eV/Å |
| 0.3 bohr | 0.000443 eV | 6.1379 eV/Å |

真实 DFT 的相同平移能量变化约 1e-12 eV；其 45° 旋转数值误差约 4.9e-5 eV，模型同旋转能量差约 0.03994 eV。加密抑制了网格相位误差，却没有让固定权重的能量/力恢复 DFT 精度，所以不能把加密单独当作修复；还要验证能量和力的网格收敛并重新标定。

量子模型的三个探索性水 NVE 从 DFT 几何的 O–H 长度增加 2%开始，目标各 10 fs，实际在 5.8/5.8/5.75 fs 离开水几何域，最短 O–H 达到约 0.741–0.748 Å，随后停止记录。减小步长没有修复几何失稳。非驻点处的曲率还有负值和明显 Hessian 非对称误差，未作为有效振动频率验收。没有把该偏离解释成化学反应。

本轮支持的结论是：**局部几何能量与同步核更新可以复现水单体性质；当前有限电子映射未验证正确电子结构和反应涌现。** 先前的自电离、复合、自由能与速率目标仍未通过。

下一步按证据排序：

1. 首先检查电子/有效核芯能量闭合与网格上的能量、力收敛；采用收敛设置重新采集匹配密度、训练和验收，不把粗网格补偿当作物理规律。
2. 对电子求解步数、核与云宽度的驻点、基组/度量多项式做控制实验，先恢复三轴极化和同能量的力定义；纯几何对照保留为稳定基准。
3. 重新训练后先通过水稳定性与完整 Zundel 留出面，再扩展大距离的质子扫描范围和柔性邻域、H₃O⁺/OH⁻/中性离子对溶剂化数据。达到门槛后才开展长质子接力与复合统计。
