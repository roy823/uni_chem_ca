# 训练与参考数据的职责 · v0.4

当前生产量子基线不训练网络。电子自洽迭代是在固定核几何上求解物理状态，不是把分子能量标签训练进模型。标准原子基组也不是分子专用反应规则。

原始公开 DFT 数据、已生成的 H/O 能量/力/密度及来源 manifest 仍保留。不同泛函、基组和边界不能直接混合绝对能量。它们供后续物理精度评估与闭合研究使用，不会改变当前无网络 HF 基线。

v0.3 的 LocalQuantumResidual、网络核种子/云宽度和 KernelUnrolledPredictor 训练路径已经从当前运行时删除。其训练与失败记录在 `docs/history/v0.3/` 和历史输出目录。

神经网络如需重新进入底层，职责应明确为经过验证的物理闭合或求解加速，并保持同一变分能量、Fock 与核力。首先独立通过无网络的量子求解器验证，不能先用学习残差补偿未知底层误差。
