# 扩展物理量子核心

电子求解器需要块重叠 S、块核 Hamiltonian h、有效 AO 掩码、核能以及一致的 `energy_focks(densities)` 接口。SCFSolver 不依赖分子名称、反应路径或核坐标的特定排列。

新能量闭合必须从同一能量给出自旋 Fock 算子；新积分供应器必须给出一致的核导数和重叠导数。核力需要处理非正交基组的 Pulay 项，并在电子收敛后验收。离散场、密度拟合、赝势或交换关联不能只增加一个力项而不更新对应能量与电子算子。

扩展按顺序进行：先用固定真实积分和小型独立对角化验证电子态，再与同方法外部参考比较能量/力，随后检查刚体协变、场响应、几何/频率和步长收敛，最后研究反应与大系统。

稠密 C/P/S 和对角化限于显式的小体系验证工具。生产路径继续使用原子块和受控资源；无法达到精度时报告失败，不回退到已删除的旧量子状态或学习势能。
