# 无学习量子基线 · v0.4

当前基线使用真实全电子 HF 算子、零温密度核和自洽求解，所有原子按同一规则更新。生产没有学习能量、网络电子种子或分子专用修正；成熟库提供原子块积分，电子求解及同步演化由本项目执行。

v0.3 独立验收揭示的软占据缺口已从表示层替换。相同积分下的 11 个案例全部通过，H₂⁺ 的固定激发态混合消失，水从未收敛的辅助坐标优化变为实际自洽 Fock 解。

本轮还完成中性分子/离子、核力、三轴场导数、刚体协变、原生重启和真实无网络水的几何/频率/NVE 验证。详见 [VALIDATION.md](VALIDATION.md) 与 [ARCHITECTURE.zh-CN.md](ARCHITECTURE.zh-CN.md)。

该验证针对声明的 HF/基组物理层，不证明完整电子相关、实验振动频率、通用反应自由能或大型体系成本。真实积分供应器和密度填充仍有资源边界，见 [PHYSICS_SCOPE.md](PHYSICS_SCOPE.md)。

原来的失败记录保持原样，存于 [v0.3 独立验收](history/v0.3/QUANTUM_BASELINE.zh-CN.md)；旧代码只作为源码快照与研究输出保存，不进入兼容运行时。
