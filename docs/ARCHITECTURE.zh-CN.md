# 当前架构

```text
World：核身份/坐标/动量 + 局域核图/自旋数 + latent
  → 局域 AO 样本
  → 块稀疏重叠、动能与正密度核
  → 密度、物理场与共享标量能量
  → 自动微分和同步提出
  → 约束检查、统一提交新 World
  → 只读观察与条件统计
```

`PreparedWorld` 只属于一个一致快照，派生视图不作为跨步缓存。

训练路径为真实参考 → 共享核种子/宽度/残差 → 有限电子展开 → 能量/力/密度监督。

原生执行器持续推进 World；预测器轨迹每次从确定性电子种子构造有限电子映射。这两条路径的力定义和记忆性质必须独立审计。

`benchmarks.py` 提供原生同步控制和家族参考筛查；`reference_design.py` 只产生未标注几何任务。`analysis/` 不给执行器发送反应指令。

当前 checkpoint schema 3；旧 schema 和稠密/Cayley 路径没有兼容迁移。
