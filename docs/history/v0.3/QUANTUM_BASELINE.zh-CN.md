# 不依赖学习残差的量子元胞独立验收

本轮关闭神经网络能量残差、网络电子初始化、网络云宽度、latent 更新与外加场，没有进行训练或根据参考答案调整生产参数。原有量子映射、原生电子求解器、演示能量和同步执行器保持原样。

结论是：**块稀疏矩阵映射和电子数/Pauli 约束通过独立核对，原生更新能产生双原子靠近和结合势阱；当前实现尚未通过零温基态与正确化学的验收。** 不能把全部失败归因于后来加入的场模型。

## 验收如何隔离误差来源

| 层次 | 测试内容 | 避免混淆的方式 |
|---|---|---|
| 表示与代数 | 生产块稀疏映射与独立 NumPy 稠密多项式、Brent 电子数求根比较 | 不复用生产的度量滤波或化学势求根函数 |
| 同一量子能量 | 单电子 H₂⁺：双方使用相同 STO-3G 重叠和核势积分 | 没有电子间相互作用、交换关联、网格 Poisson 或学习势能的误差 |
| 多电子表示/求解 | H₂、水的相同 RHF/STO-3G 积分与参考密度比较 | 使用同一 HF 能量表达，不拿 HF 绝对能量和 PBE0 混合 |
| 当前生产模型 | 原有 DemoOrbitalEnergy + LocalQuantumBackend + LocalKernelRelaxer | 不替换为参考求解器，不添加能量残差；直接检查它实际产生什么 |
| 原生更新 | SynchronousEngine 推进两个 H 的运动 | 没有预设键、反应名称、产物或几何约束 |

稠密积分和对角化只用于小体系验收，最多 16 个有效 AO、8 个原子；不进入生产量子后端。[PySCF SCF 理论与接口](https://pyscf.org/user/scf.html)提供参考积分与 HF 解。单电子参考通过广义本征问题求解，是该固定基组内的精确解，不是完备基组或实验精度声明。

每个矩阵案例采用两组独立冷启动（seed 11、29），不把参考密度或参考轨道注入初始化。默认映射采用生产研究设置：度量多项式 64 阶、占据多项式 4 阶、原始核坐标界 ±8。矩阵验收不施加额外的几何接触包络，直接检查这个映射；原生网格验收完整保留生产包络和邻域逻辑。

阈值写入各自 `protocol.json` 后才运行对应验收：矩阵差 1e-9、电子数/Pauli 容差 1e-9、坐标投影梯度 1e-6、同一 Hamiltonian 总能量差 1e-6 Hartree、参考密度差 Frobenius 范数 1e-4。它们检查求解精度，不等同分子实验误差或基组误差。

## 数学实现通过的部分

11 个案例包含 8 个 H₂⁺ 距离、H₂、水和氢原子。两次冷启动的生产映射与独立稠密重建最大矩阵差约 9.99e-16，最大电子数偏差约 8.88e-16，物理 AO 度量下的占据谱符合 Pauli 区间。原生网格能量用独立 AO 网格矩阵和差分动能积分重建，最大能量差约 2.66e-14 Hartree。

单轨道氢原子的同基组基态通过。双元胞单电子状态的失败因此不是整个矩阵代码不能运算，也不是简单电子数守恒失效。

## 同一 Hamiltonian 的基态没有通过

| H₂⁺ 核间距 | 局域映射相对精确基态的能量偏高 | 坐标求解 |
|---|---|---|
| 0.6 Å | 0.52466 eV | 已收敛 |
| 0.8 Å | 0.38053 eV | 已收敛 |
| 1.0 Å | 0.28034 eV | 已收敛 |
| 1.2 Å | 0.20718 eV | 已收敛 |
| 1.4 Å | 0.15245 eV | 已收敛 |
| 1.8 Å | 0.08100 eV | 已收敛 |
| 2.4 Å | 0.02954 eV | 已收敛 |
| 3.0 Å | 0.00977 eV | 已收敛 |

两组冷启动的单电子能量符合到约 2.22e-16 Hartree。1.0 Å 处的度量缺陷界约 6.36e-13，表明该案例的主要偏差不是度量多项式精度或没有找到坐标驻点。

该处精确单电子基态占据是 `[0, 1]`，当前映射得到约 `[0.019746, 0.980254]`，幂等缺陷 Frobenius 范数约 0.02737。它是合法的混合占据，却不是这个非简并零温基态。

当前正 Bernstein 构造保证 `0 ≤ Pσ ≤ 1`，系数来自固定有限区间的 sigmoid，占据映射在非满占据/非空占据时保持有限软化；原始坐标还受到 ±8 界限制。**保全 Pauli 上界没有同时保证零温占据的表达精度。** 这里的幂等要求针对单电子基态和所选 HF/KS 单行列式模型；不应推广为“所有相关多电子体系的 1-RDM 都必须幂等”。

1.0 Å 的诊断变化如下，均未改变生产代码：

| 占据阶数 | 原始核界 | 基态能量偏高 | 坐标收敛 |
|---|---|---|---|
| 4 | ±8 | 0.28034 eV | 通过 |
| 16 | ±8 | 0.09087 eV | 通过 |
| 64 | ±8 | 0.18637 eV | 未通过 |
| 16 | ±64 | 0.04022 eV | 通过 |

增阶/放宽坐标能改善部分误差，但不构成严格零温解的验收，也不能把未收敛的 64 阶结果作为更高精度。当前能量中没有与该软占据对应的真实电子温度和熵项。

多电子 H₂ 的相同 RHF/STO-3G 参照能量偏差约 1.333 eV，坐标收敛；水偏差约 41.98 eV，坐标投影残差约 0.526，未收敛。水的误差包含求解失败，不能仅据这个数单独量化表示误差。

## 原有无网络模型产生了什么

原有 H 单轨道演示基组的无网络双原子扫描确实出现吸引与能量最低区。0.3–3.5 Å 的离散采样最低点为 1.0 Å，相对于该模型两个原子自身的结合能约 -10.015 eV；这只是采样最低点，不是优化后的精确键长。

独立 RHF/STO-3G 在 0.74 Å 的原子参照结合能约 -4.996 eV。两个模型的基组和能量表达不同，该点用于观察明显的化学偏差，不用于认证精确 H₂ 解离能；没有直接混合它们的绝对总能量。

原生引擎从 1.5 Å、零动量初态推进 100 步（0.05 fs/步），在 5 fs 内自己靠近到约 0.453 Å 后反弹。最大能量平衡误差约 0.00256 eV，电子坐标按声明容差收敛；更新函数没有获得键或反应指令。它显示原始量子表示与能量已经能产生双原子结合趋势和核运动。

该初态在有限距离已经具有负相互作用能，不能把结果描述为两个从无穷远自由入射的原子完成稳定捕获。结合强度明显不准，轨迹也不代表正确 H₂ 振动或反应动力学。

水使用原有 H/O 研究基组、固定云宽度、零网络、零外场，在同一几何上先后增加 30/120/480 次迭代预算。累计 630 次迭代后投影残差约 0.300，仍高于 1e-6；末态与 PBE0 参考的诊断核力 RMSE 约 27.95 eV/Å。因为电子未收敛，该数不是已完成的 Born–Oppenheimer 精度评估。云宽度没有被原生求解器优化，其梯度范数约 3.25，不能称为所有电子自由度都已驻定。

水固定核坐标的半格整体平移能量差约 0.018–0.035 eV，仍存在网格相位误差。原来的平滑有效核芯、简化交换、缺少经过验证的赝势/相关处理等物理问题也仍存在。

原定 2e-4-bohr 固定核坐标力差分在水末态一个采样分量的误差为 3.79e-5 原子单位，未过 2e-5 门槛；保留这个失败记录。随后将差分步长逐次减半，误差约为 9.47e-6、2.37e-6、5.92e-7，表现出二阶差分收敛。该后续诊断支持此分量的自动微分实现，但不是完整的 BO 力或全域导数验收。

## 架构判断与后续顺序

1. 块稀疏表示、正性/Pauli 构造和数值核更新有通过独立验证的部分。
2. 当前占据参数化和电子求解尚不满足选定的零温量子基态要求；这是底层表示/求解的问题，单电子同算子实验已经排除了学习残差、交换关联和后续场的干扰。
3. 原有演示能量能产生结合趋势，但不能据此认证正确的成键能量、水分子或反应。正确化学涌现保持 `false`，自由能和速率不报告。
4. 优先建立可控制收敛的零温密度核表示；明确有限温度模式的物理温度和自由能。然后检查全部所声明电子自由度的驻点与力，换成明确且经过验证的量子化学能量闭合，再重新验收原生同步演化。

本轮没有修改生产 Hamiltonian 或占据映射，也没有用稠密参考求解器替代量子元胞。有限 halo 的大系统标度、多 GPU、真实反应统计和核量子效应不属于本轮已验证范围。

## 文件与复现

```bash
# 需要已有 PySCF 环境，仅生成小体系验证积分
python examples/generate_quantum_oracles.py

# 主环境：无训练、无 checkpoint 模型加载
python examples/audit_quantum_oracles.py
python examples/audit_native_quantum.py
python examples/audit_pair_motion.py
python examples/plot_quantum_baseline.py
```

原始参照在 `data/quantum_oracles/`；两个验收报告分别为 `outputs/quantum_baseline/oracle/report.json`、`outputs/quantum_baseline/native/report.json`。原生电子状态快照、运动轨迹和后续差分诊断保存在 `outputs/quantum_baseline/native/`。全轮汇总在 `outputs/quantum_baseline/summary.json`，PNG/PDF 图在 `outputs/quantum_baseline/figures/`。

软件回归实际为 96 passed；它表示所测试代码行为通过，不意味着所有物理验收通过。
