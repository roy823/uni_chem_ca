# 扩展与实验要求

保持块稀疏表示、整体量子约束、连续核位置和共享快照。新增能量项进入同一个标量，不以直接改核力或降低某类反应势垒代替。

基组改变要记录身份、核芯和数据约定；完整角向 multiplet 对旋转协变重要。矩阵函数改变要验证整体谱、电子数和高阶导数，再测性能。

分布式版本必须定义块与 halo 所有权、界面归约与粒子数约束。单机稀疏图不等于分布式已实现。

新增化学实验先通过同方法静态能量/力与电子状态检验，再检查时间步、网格、温度、平衡和事件统计。细化方案见 EXPERIMENTS.zh-CN.md。

模型消融改变了物理假设，应按相同数据预算分别训练。同步调度对照只改变执行顺序和分块，不同时更换力定义。

观察者只读；增强采样在独立实验层记录偏置和重加权。速率研究不能用平衡自由能验证代替动力学时钟。

每次数值改变运行 pytest 与相应参考检验。性能优化保持 float64 小体系误差对照；旧路径直接删除，不增加隐藏 fallback 或迁移。
