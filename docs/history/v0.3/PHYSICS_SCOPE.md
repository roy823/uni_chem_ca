# 物理与计算范围

已实现局域原子块电子坐标、整体正性/Pauli 构造、自旋数约束、有限多项式 halo、同能量梯度、周期/孤立场，以及真实参考数据、训练和只读观察。

研究基组与演示能量缺少经过验证的赝势、相关闭合和完备基组。真实残差训练提供标定路径，但当前独立化学精度尚未通过。

有限多项式限制状态表达能力。电子数/Pauli 保全不代表幂等性、电子驻点或真实化学。没有强关联、复杂自旋、激发态、非绝热或核量子效应验证。

无学习基线进一步实测：生产映射与独立稠密算法吻合到约 1e-15，但同一单电子 Hamiltonian 的零温基态占据仍含约 1.97% 的激发态混合。该结果针对非简并单电子与所选单行列式参考，不将幂等性作为一般相关多电子 1-RDM 的要求。具体验收见 [QUANTUM_BASELINE.zh-CN.md](QUANTUM_BASELINE.zh-CN.md)。

原子核连续，云跨越多个格点；有限网格引入平移/旋转误差，需要收敛检查。孤立卷积的自单元积分有明确近似，周期带电背景不能与孤立标签混用。

全世界没有稠密 C/P/S，但 halo 填充可能很大。没有致密水的十万原子或分布式执行证明。

数值扩散的全局传播是共享局域算子的结果，不是学会化学。既有预测器核动力学也不能单独证明原生 CA 电子记忆的作用。进一步因果对照必须保持能量、力定义与数值精度一致。

几何离子候选、持续质子转移和真实电荷状态是不同观察量。短轨迹缺少事件时不制造自由能或速率；体相 pKw 需要充分溶剂、平衡与有限尺寸研究。
