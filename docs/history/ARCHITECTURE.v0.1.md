# 架构规范：同步扩展原子元胞

## 1. 世界的基本对象

World = (Grid, Species[], AtomState, ElectronState, LatentState, clock)。
所有持久化状态均采用 structure-of-arrays，便于批量张量计算。
派生密度、场、支持映射放在 PreparedWorld 中，不与旧状态缓存混用。

原子编号是独立、唯一的 int64 身份。它不是格点编号，不是分子编号。
原子的几何中心由连续核位置 R_i 给出，不执行 `R_i = grid[index]`。

电子云由以核为中心的 AO 模板和环境相关尺度构造。电子轨道可以跨多个原子，
因此不存在“一个电子对必须永远归属于某个原子”的结构限制。

## 2. 格点与空间占据

Grid 是周期正交盒上的 cell-centred finite-volume lattice。
每个格点代表一个体积 ΔV = h_x h_y h_z。
支持关系存为 COO 风格三组数据：

```python
SupportMap.atom_index       # (E,) 原子索引
SupportMap.voxel_index      # (E,) 格点索引
SupportMap.displacement     # (E,3) 连续最小镜像位移
```

一个原子有多行，一个格点也可以有多行。没有单值 owner[voxel]。
球形截断只是包住电子云的计算范围；内部的电子分布可以有 p 轨道节点和方向性。

模板幅度使用 exp[-r²/(2σ²)]，乘 s/p 角向函数和 C2 截断窗。
基函数宽度由 Species 和 AtomState.log_width_scale 共同决定。
参考截断半径为 4.5 倍最大局域宽度。截断窗在最后四分之一半径内平滑趋零。
这些参数是演示基函数参数，不是实验原子半径数据库。

因为电子云有尾部，代码不定义唯一“硬原子边界”。实际大小诊断使用密度二阶矩。
多原子体系的分原子矩依赖选定的正权重密度分区；它不是唯一的量子可观测量。

支持拓扑的选择离散，窗在边界的一、二阶导数为零，减少跨支持边界的梯度跳跃。
仍必须进行网格和截断收敛检验。格点不会自动提供连续旋转对称性。

## 3. 核与电子尺度不同

核在连续位置上运动。core_smearing 是把有效核芯电荷沉积到网格时的数值平滑长度，
不是核的真实尺寸，也不是原子半径。当前电子云与核芯不是同一几何球。

参考 O 为 Z=8、有效核芯电荷 +6；两个冻结的核层电子不显式重建。
H 为 Z=1、核芯电荷 +1。使用其他核芯约定时必须同时修改电子数、训练标签和能量模型。

## 4. 电子态与约束

ElectronState = (Q[B,K], occupations[K,2])。
Q 为原始占据子空间系数；K 是空间电子轨道数量，不是固定的全局小常数。
AO 总数 B 通常随原子数增长。自旋采用共享空间轨道、共线两通道近似。

在当前网格样本 A 上计算 S=AᵀAΔV，令 QᵀSQ=LLᵀ，C=QL⁻ᵀ。
得到 CᵀSC=I，从而保证 P=C diag(n) Cᵀ 的离散 N-representability：
每种自旋本征占据在 [0,1]，总价电子数为 Tr(PS)，rho>=0。

不允许用“Tr(P)=N”替代非正交 AO 的 Tr(PS)=N。
不允许只把 P 的对角线裁剪到 [0,2] 并声称满足 Pauli 约束。
不允许用隐藏 jitter 修复秩亏再声称电子数完全不变；参考实现直接报错。

实现允许输入分数占据，但默认演化不改变占据本征值和自旋扇区。
因此它不是任意强关联、断键开壳层和电子跃迁的完整描述。
要研究需要占据数重分配的过程，应扩展电子后端而不是编写断键反应表。

## 5. 能量、静电和力

PreparedWorld 在同一快照上构造 rho、核芯电荷密度和净电荷密度。
场满足离散周期 Poisson 方程：-Δ_h φ=4π rho_charge，mean(φ)=0。

使用与前向面梯度/后向散度相容的离散 Laplacian 符号做 FFT 求解。
因此 1/2 Σ rho φ ΔV 与 Σ |E_face|² ΔV/(8π) 一致。
E_face 是面心电场，不可误当 cell-centred 向量场使用。

周期非中性体系默认拒绝。只有显式请求 neutralizing_background 才引入均匀补偿背景。
中性电荷沉积的浮点误差有随 dtype 和绝对电荷规模变化的容差，不被误判为净电荷。
显式表示电子/核芯时不再随意乘一个水的宏观介电常数，以免重复极化。

F=-dE/dR 由同一离散总能量自动微分得到，包含移动基函数、重叠重正交和沉积的导数。
不是用另一个无约束网络输出力，也不再额外叠加 Z E 导致静电重复计数。

注意两种力的区别：Evaluator 在固定独立电子坐标 Q 下求偏导；
UnrolledPredictor 对整个有限步电子预测映射求全导数。
只有电子达到相应变分驻点、并且能量模型本身可信时，才能讨论 BO 力。

## 6. 同步执行协议

每个阶段都有 snapshot → batched propose → global constraints → commit。
核、电子、场可以有不同的求解时间尺度；并行不要求所有自由度使用相同物理 timestep。

```text
W_t
 ├─ 同一 R_t：全部电子 AO 行并行提出候选 → 重新计算场 → 全局线搜索提交
 ├─ 统一 F_t：所有核同时 half-kick + drift
 ├─ 同一 R_{t+dt}：全部电子重新同步弛豫 → 重新计算场
 ├─ 统一 F_{t+dt}：所有核同时完成 half-kick
 ├─ 旧 latent + 一致的旧位置场：所有 latent 格点同时计算面通量与记忆更新
 └─ 校验全部新状态 → 一次提交 W_{t+dt}
```

电子迭代内部也是全局 Jacobi 式屏障，不是按 atom_id 顺序就地更新。
全局 Cholesky 和 FFT 是该模型的显式非局部步骤；不能称它为纯最近邻 CA。

dataclass(frozen=True) 只冻结字段绑定，不能让 PyTorch Tensor 的底层内存物理只读。
库内遵循不就地修改输入的协议；引擎输出做 detach+clone，防止跨步别名与计算图累积。
外部插件必须遵守同一协议。测试检查输入不变和原子排列置换等变性。

## 7. latent 的职责

ConservativeLatentCA 用共享网络生成有界正 mobility，再由成对面通量更新。
周期边界下通量相消，使每个通道总和守恒。记忆是本地指数更新。
显式时间步检查一个足够的稳定性条件，不静默裁剪数值。

它还不是经轨迹训练的反应坐标、动力学流形或满足涨落耗散的热浴。
当前 latent 进入 SharedElectronicPreconditioner，只影响数值收敛速度。
这把“保留宏微观闭环接口”与“伪造物理驱动力”分开。

未来要让 latent 驱动真实物理，必须定义条件状态、能量或自由能、记忆、噪声、
守恒律和时间标定。增强采样也必须区别重加权平衡统计与真实反应速率。

## 8. 时间与可重复性

采用原子单位：长度 bohr、能量 Hartree、质量 electron mass、时间 atomic time。
示例 dt=0.1 大约是 0.00242 fs，不是 0.1 fs。
这个值只是保守的数值示范，不是效率优化结果。

初始电子子空间和示范模型初始化均有局部随机种子，不改变应用全局 RNG。
CPU 测试使用 float64。GPU scatter/reduction 可能有不同加和次序，
同步数学语义不意味着跨设备逐位一致；CUDA 本次未实际验证。
