# v0.4 设计取舍

底层先独立满足明确物理方法的能量、电子态和核力，再扩展复杂能力。生产使用原子块密度核与算子，反应标签和分子类型不进入更新函数。

原来的软占据、硬辅助坐标界、演示 Hamiltonian、单步网络电子映射及其变分/全导数双路径已经删除。v0.4 不迁移旧权重或检查点。历史实验用于比较，不作为兼容运行时。

长期保留的边界是：状态、块代数、零温密度构造、自洽求解、物理积分/能量闭合、同步核更新和只读分析。更快的积分供应器或更完整的物理闭合可以在相同电子求解接口中验证，不能用分子专用修正替代这些责任。

PySCF 是成熟的积分库依赖；生产只调用局域 shell-slice 积分，不调用其 SCF 或全局密度/轨道求解。实际项目核心自行求解电子态。[PySCF 的物理方法定义](https://pyscf.org/user/scf.html)也用于独立对照。

当前从最小可工作的全电子 HF 层开始。它不是完整电子相关理论，但已能对同一方法的真实量子参照、解析核力和分子振动进行端到端验证。适用范围见 [PHYSICS_SCOPE.md](PHYSICS_SCOPE.md)。
